# Raporty zaliczeniowe (zajęcia cząstkowe)

Każdy folder `zajecia-XX` zawiera raporty wysyłane na e-portal **do godz. 22:00 w dniu poprzedzającym zajęcia**.

| Folder | Zajęcia | Zakres |
|--------|---------|--------|
| [zajecia-03](zajecia-03/) | 3 | Temat, zespół, technologie, opis (3 zdania), plan prac, metryki |
| [zajecia-05](zajecia-05/) | 5 | Krok optymalizacji 1 — responsywne obrazy WebP + postęp |
| `zajecia-07` | 7 | Krok optymalizacji 2 + postęp |
| `zajecia-09` | 9 | Krok optymalizacji 3 + postęp |
| `zajecia-11` | 11 | Działający system, raport przed optymalizacją |
| `zajecia-13` | 13 | Wyniki testów optymalizacji |

**Format kanoniczny:** `RRRR-MM-DD-raport-zajecia-XX.html` + motyw [`theme/report.css`](theme/report.css).

- Spis raportów: otwórz [`index.html`](index.html) w przeglądarce.
- Zasady spójności: [`RULES.md`](RULES.md) · szablon: [`templates/raport-szablon.html`](templates/raport-szablon.html).
- Zajęcia 3: [`zajecia-03/2026-10-20-raport-zajecia-3.html`](zajecia-03/2026-10-20-raport-zajecia-3.html)
- Zajęcia 5: [`zajecia-05/2026-11-24-raport-zajecia-5.html`](zajecia-05/2026-11-24-raport-zajecia-5.html)

Opcjonalnie archiwum Markdown: `*.md` w tym samym folderze.
